# Amendment 20260915T170000Z — pre-emission invariance admission test

**Item amended:** SPEC §10.2 and §11 Stage 6 (the *test design* of the pre-emission
invariance gate). No frozen configuration value changes: `configs/mvp.yaml`
`invariance_atol_bfloat16: 0.02` and `invariance_atol_float32: 1e-5` are unchanged, so the
resolved configuration hash (`9bad4b36…960ff`) and every Stage 3–5 identity are unchanged.
Authorised by the user on 2026-09-15 after the Stage 6 investigation (`docs/stage6_plan.md`).

**Reason.** The truncated-prefix comparison confounds two things: dependence on future
tokens (the scientific invariant) and GPU BF16 kernel selection by sequence shape. Measured
on the H100 PCIe with the pinned model and `configs/smoke.yaml` (`330:correct`, first 16
boundaries): prefixes of 70 and 86 tokens differed from the full replay from layer 1 onward
(max abs 4.5 and 2.0 at layer 48, 90,926 of 250,880 elements above 0.02); all 14 boundaries
with prefixes of 112+ tokens were bitwise identical; the MATH SDPA backend showed the same
effect; repeat runs are deterministic; replacing every future token while preserving the
sequence length gave exactly zero difference at every boundary and every site. An absolute
tolerance of 0.02 is below BF16 resolution at the observed residual magnitudes (ulp 2.0 for
values in [256, 512)), so the truncated-prefix test cannot pass except by bitwise identity.

**Amendment.** The primary admission gate is the same-shape future-token mutation test:
prefix and boundary fixed, every token strictly after the boundary replaced, same-length
replay, per-site comparison at the existing tolerance. Truncated-prefix replay is retained
and reported as a diagnostic (`invariance_report.json`, per boundary and per site) and
never gates admission. `tests/scientific/test_preemission_invariance.py` and
`tests/unit/test_activation_hooks.py` implement both; the latter also proves that a
prefix-only discrepancy with exact same-shape invariance never passes a leaky extractor.

**Alternative rejected.** Loosening the tolerance, switching to a relative criterion, or
restricting the prefix test to long prefixes: each keeps a confounded test as the gate.
AGENTS §5.1 still lists prefix-only equality; AGENTS is not regenerated by agents, and the
conflict is recorded in `docs/decisions.md` for the user.
